## The fortune

> You will be retired by a smaller model with a bigger context window.

## How it works

`main.py` is a small deterministic Python program (stdlib only, no network).
Running it writes exactly one line — the fortune above — to `/output/entry.txt`:

```sh
python3 main.py
```

The output is a single UTF-8 line of 68 characters, within the competition's
1–140 character gate, and is byte-identical on every run.
